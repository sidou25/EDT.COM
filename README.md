# 📅 EDT.COM — Emploi du temps de révision pour les L1 Informatique

> Un site simple que j'ai créé pour les étudiants de **1ʳᵉ année (L1) Informatique** de ma faculté, l'**Université d'Alger 1**, pour qu'ils puissent **réviser chaque module avec des cours vidéo YouTube** et s'organiser toute la semaine.

**🇬🇧 [English version below](#-english-version)**

---

## 💡 Pourquoi ce projet ?

En L1, beaucoup d'étudiants ont du mal à suivre : beaucoup de modules, peu d'organisation, et des heures perdues à chercher **la bonne vidéo** pour comprendre un cours.

J'ai donc réuni au même endroit :
1. **les meilleures vidéos YouTube** pour chaque chapitre ;
2. **un planning de révision** pour toute la semaine ;
3. **des règles simples** pour rester discipliné.

## ✨ Ce que contient le site

### 📚 Les modules (avec 20 liens vers des cours vidéo)
| | Module |
|---|---|
| 🖥️ | Algorithmique (champs, listes, pointeurs…) |
| 📐 | Analyse |
| ⚙️ | Structure machine |
| 🔢 | Algèbre |
| 🎲 | Probabilités & statistiques |
| ⚡ | Physique |
| 💻 | TIC |
| 🧮 | OPM |

Un clic sur un chapitre ouvre directement la vidéo sur YouTube.

### 🗓️ Planning hebdomadaire
Un emploi du temps de révision jour par jour, pour savoir **quoi réviser et quand**.

### 📋 Conditions
Les règles à respecter pour que le planning fonctionne vraiment.

## 🛠️ Technologies

- **HTML5**
- **CSS3** (design responsive, adapté au téléphone)

Pas de framework, pas d'installation : ça marche partout.

## 🚀 Lancer le projet

```bash
git clone https://github.com/sidou25/EDT.COM.git
cd EDT.COM
```

Puis ouvrir `index.html` dans le navigateur.

## 🇬🇧 English version

**EDT.COM** is a study-timetable website I built for **first-year Computer Science students (L1)** at my faculty, the **University of Algiers 1**.

It gathers, in one place:
- **YouTube video lessons** for every chapter of the 8 first-year modules (algorithms, analysis, computer architecture, algebra, probability & statistics, physics, ICT, OPM) — 20 hand-picked videos;
- a **weekly revision schedule**;
- a set of **rules** to stay disciplined.

**Tech:** HTML5, CSS3 — no framework, works on any device.
